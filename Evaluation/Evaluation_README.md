# Security Evaluation — D4 Comparison Script

## Overview
This script quantifies the security improvement achieved by introducing HMAC-SHA256 authentication. It parses the attacker logs generated in Phase 1 (vulnerable server) and Phase 2 (HMAC-secured server) and produces a side-by-side comparison of attack success rates.

## Files
- 'security_evaluation.py' — reads both attacker log files and computes the before/after comparison table

## Dependencies
This script uses only Python's built-in modules — no installation needed.

## Prerequisites
Both attack phases must have already been executed and their logs
generated:
- 'Attacker.log' — generated by running the Phase 1 attacker against the vulnerable server
- 'HMAC_Attacker.log' — generated by running the Phase 2 attacker against the HMAC-secured server

Make sure both log files are present in the same directory as 'security_evaluation.py', or update the file paths inside the script to point to their correct locations.

## Running the Evaluation
```bash
python3 security_evaluation.py
```

## Output
The script prints a comparison table showing:
- Total attack attempts per phase
- Successful attacks per phase
- Failed (blocked) attacks per phase
- Attack success rate (%) per phase
- Overall security improvement in percentage points

## Expected Result
| Metric | Phase 1 (Vulnerable) | Phase 2 (HMAC) |
|---|---|---|
| Attack Success Rate | ~100% | 0% |

## Significance
This comparison is the core finding of the project: introducing HMAC-SHA256 authentication eliminates impersonation attacks that succeed completely against MAC-address-only authentication. This result directly supports the project's research questions on whether cryptographic authentication can mitigate identifier-spoofing attacks
in constrained IoT environments.
