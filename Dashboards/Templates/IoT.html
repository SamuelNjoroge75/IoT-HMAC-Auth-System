ℹ What is happening?

This VM simulates an IoT temperature sensor. It generates random temperature readings between 20–40°C and sends them to the Ubuntu Server VM over HTTP as HTTP requests.

Phase 1 — The device authenticates using only its MAC address. The server accepts any request that carries the right MAC address, which an attacker can spoof easily in a local network.

Phase 2 — The device signs each data packet using HMAC-SHA256 with a pre-shared secret key. The server verifies the signature before accepting any data, so a spoofed request without the key will be blocked.
