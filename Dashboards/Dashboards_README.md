# Dashboards

## Overview
Each VM in this project has a browser-based dashboard that allows you to control and monitor scripts without using the terminal directly. The dashboards are built with Flask for the backend development and plain HTML/JavaScript for the frontend development.

---

## Structure

```
Dashboards/
├── server_dashboard.py
├── client_dashboard.py
├── attacker_dashboard.py
└── templates/
    ├── server.html
    ├── IoT.html
    └── attacker.html
```

---

## Dashboards

### Server Dashboard — `server_dashboard.py`
**VM:** Ubuntu Server | **URL:** http://<"server's IP Address">:8080

- Start and stop `Vulnerable_server.py` (Phase 1) and `HMAC_server.py` (Phase 2)
- View live script activity separately from the server auth logs
- See authentication stats: accepted vs rejected requests per phase
- Side-by-side phase comparison with progress bars

### IoT Device Dashboard — `client_dashboard.py`
**VM:** IoT Device | **URL:** http://<"device's IP Address">:8081

- Run `IoT_device.py` (Phase 1 — MAC address only) or `HMAC_IoT_device.py` (Phase 2 — HMAC signed)
- View live script output with colour-coded status messages
- Displays the last transmitted temperature and a bar chart of recent readings

### Attacker Dashboard — `attacker_dashboard.py`
**VM:** Attacker | **URL:** http://<"device's IP Address">:8082

- Run `Nmap_discovery.py`, `Attacker_device.py` (Phase 1 attack), or `HMAC_attacker.py` (Phase 2 attack)
- View attack stats: total attempts, successes, blocked, and success rate
- Before vs after comparison of attack success rates across both phases

---

## Requirements

Install dependencies on each VM before running:

```bash
pip install flask flask-cors requests
```

---

## How to Run

Run each dashboard on its respective VM from inside the `Dashboards/` folder:

```bash
python3 server_dashboard.py      # Ubuntu Server VM
python3 client_dashboard.py      # IoT Device VM
python3 attacker_dashboard.py    # Attacker VM
```

The dashboard will open automatically in the browser. If it does not, open the URL manually using the table above.

---

## Notes

- The HTML files must be inside the `templates/` folder — Flask requires this.
- Run only one server at a time (`Vulnerable_server.py` or `HMAC_server.py`) — both use port 5000.
- The `device_keys.json` file generated by `key_generator.py` must exist before running any Phase 2 scripts.
